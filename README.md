# 考试题型与分值

> [!important] 成绩构成
> - 练习作业 + 考勤：**20%**
> - 实验：**20%**
> - 期末考试（闭卷）：**60%**

## 期末题型（闭卷）

| 题型       | 数量         | 分值    | 小计       |
| -------- | ---------- | ----- | -------- |
| 一、单项选择题  | 15 题 × 2 分 | 2 分/题 | **30 分** |
| 二、填空题    | 20 空 × 1 分 | 1 分/空 | **20 分** |
| 三、实验题    | 1 题        | —     | **10 分** |
| 四、计算/分析题 | 4~5 题      | —     | **40 分** |

## 复习策略

- **选择+填空（50 分）**：靠各章"必背表"和高频概念，见各章笔记中的 ==必背== 高亮。
- **实验题（10 分）**：复习课程做过的实验（如网线制作、交换机配置、抓包分析等）。
- **计算分析题（40 分）**：主攻 [[08 计算分析题模板]]，重点类型：
	- 时延 / RTT / 有效数据率 / 利用率（第1章）
	- CRC 计算与曼彻斯特编码（第2、3章）
	- IP 分片、CIDR/子网划分、最长前缀匹配（第4章）
	- RIP 距离向量更新、滑动窗口（第4、5章）
	- TCP 序号确认号、握手挥手报文（第5章）
